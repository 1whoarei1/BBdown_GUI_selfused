BBDown Next Portable

使用方法：
1. 解压完整发行包。
2. 双击 BBDown Next.exe 启动。
3. 在设置页下载或选择本机 BBDown.exe 与 ffmpeg.exe。
4. 输入 B 站地址进行解析和下载。

默认下载目录：
%USERPROFILE%\Downloads\BBDown Next

账号：
- 支持 BBDown 扫码登录或 Cookie 登录。
- 退出登录会删除当前工具目录中的 BBDown.data、BBDownTV.data 和 qrcode.png。

要求：
- Windows 10/11。
- Microsoft Edge WebView2 Runtime。
- 未签名程序可能显示未知发布者提示。
